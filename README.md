# Nodi Verse

Flagship marketing site for Nodi Verse, an AI-native social media agency.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Design system

- White-first editorial canvas
- Black typography and high-contrast bands
- Nodi red `#D83A2A` used as a controlled accent
- Manrope + DM Mono
- Mobile-first responsive layout
- Reduced-motion support
- Semantic sections and accessible form controls
